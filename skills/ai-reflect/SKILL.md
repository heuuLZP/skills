# AI 协作复盘

基于真实对话证据评估人机协作，而不是评价任务完成质量。

## 流程

1. 解析时间范围，默认最近 7 天；将“2 周”“1 个月”等换算为天数。
2. 从当前 `SKILL.md` 定位 skill 目录并运行：

   ```bash
   python3 <skill-directory>/scripts/scan_sessions.py --days 7 --output /tmp/ai-reflect-sessions.json
   ```

3. 读取标准化 JSON，仅分析 `sessions[].messages` 中的真实用户消息和助手文本。脚本已排除系统提示、工具结果、审批转录、附件和子代理重复记录，并限制超长 session 与 session 总数。
4. 按 session 判断主题（编码、学习、问题排查、架构设计、其他），再评估四个维度：

| 维度 | 主要证据 |
|---|---|
| 思考深度 | 提问前的分析或尝试、上下文具体度、追问质疑、原理探索 |
| 职责分配 | 用户是否参与执行和关键决策，是否只索取最终结果 |
| 信源多样性 | 官方资料、方案对比、同事意见、测试或其他验证 |
| 能力趋势 | 与上一份报告相比的改善、持平或退化 |

5. 趋势分析时读取 `~/.agents/data/ai-reflect/reports/` 中最新报告；首次分析只建立基线。
6. 保存到 `~/.agents/data/ai-reflect/reports/YYYY-MM-DD.md`，完成后删除临时 JSON。

## 报告结构

```markdown
# AI 协作复盘报告
> 分析周期: YYYY-MM-DD ~ YYYY-MM-DD
> 生成时间: YYYY-MM-DD HH:MM
> ⚠️ 本报告由 AI 分析生成，存在自我参考局限，仅供参考。

## 概览
- 会话数、交互轮次、来源与主题分布

## 思考深度: [🟢/🟡/🔴] + 一句话结论
[2–3 个脱敏证据]

## 职责分配: [🟢/🟡/🔴] + 一句话结论
[2–3 个脱敏证据]

## 信源多样性: [🟢/🟡/🔴] + 一句话结论
[2–3 个脱敏证据]

## 能力趋势: [基线建立 / ↑ / → / ↓]
[与上次报告的具体差异]

## 建议
[3–5 条针对本次证据、可立即执行的建议]
```

`🟢` 表示状态良好，`🟡` 表示值得改善，`🔴` 表示存在明显问题。没有足够证据时明确说“不足以判断”，不要补造结论。

## 输出要求

- 每个判断引用实际对话证据并脱敏，不暴露密码、token 或私密内容。
- 区分观察和推断；建议必须具体，避免“多思考”之类空话。
- 对话中只返回四维概览、最值得关注的一点和报告路径。
- 不把原始对话或标准化 JSON 写入报告目录。
